# 路径无关与保守场
路径无关的场就是保守场
**线积分基本定理**
1.设 $\mathbf { F } = \ M \mathbf { i } + N \mathbf { j } + P \mathbf { k }$ 是一个向量场，其分量在空间连通开区域 $\mathit { D }$ 上都连续，那么存在一个可微函数 $f$ ,使得
$$
\mathbf { F } \, = \, \nabla f \, = \, { \frac { \partial f } { \partial x } } \mathbf { i } \, + \, { \frac { \partial f } { \partial y } } \mathbf { j } \, + \, { \frac { \partial f } { \partial z } } \mathbf { k }
$$
当且仅当对 $D$ 内所有点 $A$ 和 $B$ ,积分值 $\int _ { A } ^ { B } \mathbf { F } \cdot \mathbf { d r }$  与 $D$ 内连接$A, B$ 的路径无关；
2.若积分与 $A, B$ 之间的路径无关，则它的值为
$$
\int _ { A } ^ { B } \mathbf { F } \, \cdot \, \mathrm { d } \mathbf { r } \, = \, f ( \, B \, ) \, - \, f ( \, A \, ) \,.
$$
显然，这是路径无关的
**保守场环路性质**
1.沿 $\mathit { D }$ 内任一闭路线，积分 $\int \! \mathbf { F } \ \cdot \, \mathbf { d } \mathbf { r } \ = \ 0$
2.场 $\mathbf { F }$ 在 $\boldsymbol { D }$ 上是保守的.
如上两条性质等价
**保守场分量检验**
设 ${ \bf F } \; = \; M ( \, x \,, y \,, z \, ) { \bf i } \, + \; N ( \, x \,, y \,, z \, ) { \bf j } \, + \, P ( \, x \,, y \,, z \, ) { \bf k }$ 为一场，其各分量函数都有—阶连续偏导数.于是， $\mathbf { F }$ 为保守场，当且仅当
$$
\frac { \partial \, { \cal P } } { \partial \, y } \ = \ \frac { \partial \, { \cal N } } { \partial \, z } \,, \ \ \ \ \ \frac { \partial \, { \cal M } } { \partial \, z } \ = \ \frac { \partial \, { \cal P } } { \partial \, x } \,, \ \ \ \ \frac { \partial \, { \cal N } } { \partial \, x } \ = \ \frac { \partial \, { \cal M } } { \partial \, y } \,.
$$
**微分形式和全微分形式**
任一形如 $M ( \, x \,, y \,, z \, ) \, \mathrm { d } x \, + \, N ( \, x \,, y \,, z \, ) \, \mathrm { d } y \, + \, P ( \, x \,, y \,, z \, ) \, \mathrm { d } z$ 的式子都是微分形式.
空间中区域$\boldsymbol { D }$ 上的微分形式是完全的（全微分形式），若
$$
M \mathbf { d } x \; + \; N \mathbf { d } y \; + \; P \mathbf { d } z \; = \; { \frac { \partial f } { \partial x } } \mathbf { d } x \; + \; { \frac { \partial f } { \partial y } } \mathbf { d } y \; + \; { \frac { \partial f } { \partial z } } \mathbf { d } z \; = \; \mathbf { d } f
$$
对某个数量值函数 $f$ 在整个 $\boldsymbol { D }$ 上成立.（这也等价于向量场F存在势函数）

## 散度
设流体的速度场（流体在(x, y)处的速度矢量）为（M和N每一点的一阶偏导连续）：
$$
{ \bf F } ( \, x \,, y \, ) ~ = ~ {  M } ( \, x \,, y \, ) { \bf i } \, + \, {  N } ( \, x \,, y \, ) { \bf j }
$$
在研究的区域R中，绘制一个小矩形
![[Pasted image 20260518171414.png|366]]
流体穿过底边离开矩形的速率近似为（**我们认为在$\Delta x$上，速度场是不变的**，同时我们只考虑边的法向速度）：
$$
F ( \, x \,, \, y \, ) \, \cdot \, ( \, - \, { \bf j } ) \, \Delta x \; = \; - \; N ( \, x \,, \, y \, ) \, \Delta \, x \;.
$$
同理得到其他边的逸出速度（$\bf j \cdot \bf i = 0$）
顶边： ${ \bf F } ( \; x \;, y \; + \; \Delta y \; ) \; \cdot \; { \bf j } \Delta x \; = \; N ( \; x \;, y \; + \; \Delta y \; ) \Delta x$
底边： ${ \bf F } ( \, x \,, \, y \, ) \, \cdot \, ( \, - \, { \bf j } \, ) \Delta x \; = \; - \; N ( \, x \,, \, y \, ) \Delta x$
右边： ${ \bf F } ( \, x \, + \, \Delta x \,, \, y \, ) \, \cdot \, { \bf i } \Delta y \; = \; M ( \, x \, + \, \Delta x \,, \, y \, ) \, \Delta y$
左边： ${ \bf F } ( \; x \,, y \, ) \; \cdot \; ( \; - \; { \bf i } \, ) \, \Delta \, y \; = \; - \; M ( \; x \,, \, y \; ) \, \Delta \, y \;.$

加在一起：
上、下边： $( \, N ( \, x \,, y \, + \, \Delta y \, ) \, - \, N ( \, x \,, y \, ) \, ) \, \Delta x \, \approx \, \left( { \frac { \partial \, N } { \partial y } } \Delta y \right) \Delta x$
右、左边： $( \, M ( \, x \, + \, \Delta x \,, y \, ) \, - \, M ( \, x \,, y \, ) \, ) \Delta y \, \approx \, \left( \, { \frac { \partial \, M } { \partial \, x } } \Delta x \right) \Delta y \,.$
我们定义穿过单位矩形边界的通量为通量密度（或散度）:
向量场 $\mathbf { F } = \boldsymbol { M } \mathbf { i } + \boldsymbol { N } \mathbf { j }$ 在点 $( x, y )$ 处的通量密度或散度为
$$
\mathbf { d i v F } \, = \, { \frac { \partial M } { \partial x } } \, + \, { \frac { \partial \, N } { \partial y } } \,.
$$
由于规定，显然当$\mathbf { d i v F }>0$的时候是流体从该区域进入，反之则是流出
## 环量密度
> [!NOTE] 旋度
> 旋度是一个向量，这个向量的方向表示局部旋转轴方向，大小表示垂直于这根轴的小平面上的环量密度。
> 旋度向量垂直于发生局部环量的平面；它的方向表示旋转轴方向（右手螺旋法则），它的大小表示这个平面上的单位面积环量。

类似散度，不过我们研究的是沿着小矩形边界的速度
上边： $\mathbf { F } ( \; x \;, y \; + \; \Delta y \; ) \; \cdot \; ( \; - \; \mathbf { i } \, ) \, \Delta x \; = \; - \; M ( \; x \;, y \; + \; \Delta y \; ) \, \Delta x$
下边： ${ \bf F } ( \; x \;, \; y \; ) \; \cdot \; { \bf i } \; \Delta \, x \; \; = \; \; M ( \; x \;, \; y \; ) \, \Delta \, x$
右侧边： ${ \bf F } ( \, x \, + \, \Delta x \,, \, y \, ) \, \cdot \, { \bf j } \, \, \Delta y \; = \; N ( \, x \, + \, \Delta x \,, \, y \, ) \, \Delta y$
左侧边： ${ \bf F } ( \, x \,, y \, ) \, \cdot \, ( \, - \, { \bf j } ) \, \Delta y \; = \; - \; N ( \, x \,, y \, ) \, \Delta y \;,$
环量密度表示的是单位面积上的闭合边界环量

## Green 定理
### 通量-散度形式或法向形式
场 ${ \bf F } ~ = ~ { \bf M } { \bf i } + ~ N { \bf j }$ 穿过一简单闭曲线 $c$ 向外的通量等于 div $\mathbf { F }$ 在 $C$ 所围区域 $\boldsymbol { R }$ 上的
二重积分
$$
\oint _ { C } { \textbf { F } } \cdot { \textbf { n } } { \mathrm { d } } s \ = \ \oint _ { C } {{ M } } { \mathrm { d } } y \ - \ N { \mathrm { d } } x \ = \ \iint _ { R } \left( { \frac { \partial M } { \partial x } } \, + \, { \frac { \partial \, N } { \partial \, y } } \right) { \mathrm { d } } x \, { \mathrm { d } } y
$$
### 环量-旋度形式或切向形式
场 ${ \bf F } ~ = ~ { M } { \bf i } ~ + ~ {N } { \bf j }$ 绕平面简单闭曲线 $c$ 的逆时针方向的环量等于 $( \mathbf { c u r l } \ \mathbf { F } ) \cdot \mathbf { k }$
所围区域 $\boldsymbol { R }$ 上的二重积分
$$
\oint _ { C } { \textbf { F } } \cdot { \textbf { T  } } \mathrm { d }s \ = \ \oint _ { C } { { M } } { \mathrm { d } } x \ + \ N { \mathrm { d } } y \ = \ \iint _ { R } \left( { \frac { \partial { { N } } } { \partial x } } \, - \, { \frac { \partial { { M } } } { \partial y } } \right) { \mathrm { d } } x \, { \mathrm { d } } y
$$
