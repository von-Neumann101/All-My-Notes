# 面积微元
核心：
$$
dxdy=|\cos\gamma|dS\qquad \gamma为曲面法向量和z轴的夹角
$$
注意：$dS$是没有方向的，只表示普通的面积
## $z=f(x,y)$
面积微元：
$$
dS=\sqrt{1+f_x^2+f_y^2}dxdy
$$
或者也可以写为
$$
dS=\sqrt{1+z_x^2+z_y^2}dxdy
$$
例如$z=x^2+y^2$：
$$
z_x=2x,\ z_y=2y\Longrightarrow dS=\sqrt{1+4x^2+4y^2}dxdy
$$
## $F(x,y,z)=0$
面积微元
$$
dS=\frac{\sqrt{F_x^2+F_y^2+F_z^2}}{|F_z|}dxdy
$$
例如$x^2+y^2+z^2=R^2$：
$$
F=x^2+y^2+z^2-R^2\Rightarrow F_x=2x,\ F_y=2y,\ F_z=2z
$$
得到面积微元
$$
dS=\frac{\sqrt{4x^2+4y^2+4z^2}}{|2z|}dxdy=\frac{R}{|z|}dxdy
$$
可以自己算一下，这和$z=f(x,y)$算出来的结果是一样的
## $\vec{r}(u,v)=(x(u,v),y(u,v),z(u,v))$
面积微元：
$$
dS=|\vec r_u\times \vec r_v|dudv
$$
例如$\vec { r } ( \varphi, \theta ) = ( R \operatorname { s i n } \varphi \operatorname { c o s } \theta, \ R \operatorname { s i n } \varphi \operatorname { s i n } \theta, \ R \operatorname { c o s } \varphi )$：
$$
\vec r_\varphi=(R\cos \varphi\cos\theta,R\cos\varphi\sin\theta,-R\sin\varphi)
,\ \ \vec r_\theta=(-R\sin \varphi\sin\theta,R\sin\varphi\cos\theta,0)
$$
得到面积微元
$$
dS=R^2\sin\varphi d\varphi d\theta
$$
# 第二类曲面积分
$$
\iint_\Sigma\vec F\cdot \vec n dS=\iint_\Sigma Pdy\land dz+Qdz\land dx+Rdx\land dy
$$
其中向量场：
$$
\vec F = (P,Q,R)
$$
有向面积元：
$$
\vec ndS=(dy\land dz,dz\land dx,dx\land dy)
$$
## 外积
1. 线性
$$
\begin{array} { c } { ( \alpha + \beta ) \wedge \gamma = \alpha \wedge \gamma + \beta \wedge \gamma } \\ { \alpha \wedge ( \beta + \gamma ) = \alpha \wedge \beta + \alpha \wedge \gamma } \\
( f \alpha ) \wedge ( g \beta ) = f g ( \alpha \wedge \beta )\end{array}
$$
2. 交换顺序会变号
3. 自己和自己外积为零
4. 结合律
5. 行列式法则：
如果$x=x(u,v),\ y=y(u,v)$，那么：
$$
d x \wedge d y = \frac { \partial ( x, y ) } { \partial ( u, v ) } d u \wedge d v
$$
6. 转换
$$
d y \wedge d z = - z _ { x } d x \wedge d y
$$
$$
d z \wedge d x = - z _ { y } d x \wedge d y
$$
## $z=z(x,y)$
利用外积第6点
$$
\vec ndS=\pm(-z_x,-z_y,1)dxdy
$$
如果取正，那么法向量为上侧。反之则是下侧
