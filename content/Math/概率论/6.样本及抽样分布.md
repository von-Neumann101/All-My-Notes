# 随机样本
这里我会使用 *采样* 代替所有 **非定义** 段落中的 *观察*

**定义**：将试验的全部可能的观察值称为**总体**，每一个可能观察值称为**个体**。总体中所包含的个体的个数称为总体的**容量**。容量为有限的称为**有限总体**，容量为无限的称为**无限总体**

**注意**：随机变量$X$是一个**函数**，所以一个**总体**对应一个**随机变量**$X$，每一个个体都是他的一个**取值**。
从总体抽取一个个体，就是对总体$X$进行一次采样——对总体$X$进行$n$次重复、**独立**的采样

**定理**：当个体的总数$N$远大于样本的容量$n$时，可以将**不放回抽样近似为放回抽样处理**

**定义**：设 $X$ 是具有分布函数 $F$ 的随机变量，若 $X _ { 1 }, X _ { 2 }, \cdots, X _ { n }$是具有同一分布函数 $F$ 的、相互独立的随机变量，则称 $X _ { 1 }, X _ { 2 }, \cdots, X _ { n }$ 为从分布函数 $F$ （或总体 $F$、或总体 $X$ ）得到的**容量为 $n$ 的简单随机样本**，简称**样本**，它们的观察值$x _ { 1 }, x _ { 2 }, \cdots, x _ { n }$ 称为**样本值**，又称为 $X$ 的 $n$个**独立的观察值**。
也可以将样本看成是一个随机向量，写成 $( \, X _ { 1 } \,, X _ { 2 } \,, \cdots, X _ { n } \, )$ ，此时样本值相应地写成高维向量的形式：$( x _ { 1 }, x _ { 2 }, \cdots, x _ { n } )$、$( \, y _ { 1 } \,, y _ { 2 } \,, \cdots, y _ { n } \, )$，作为样本向量相应的样本值向量

显然，由独立性可得$(X_1,X_2,...,X_n)$的分布函数和概率密度（如果存在）：
$$
\begin{align*}
&F^*(x_1,x_2,...,x_n)=\prod_{i=1}^nF(x_i)\\
&f^*(x_1,x_2,...,x_n)=\prod_{i=1}^nf(x_i)
\end{align*}
$$
# 直方图和箱线图
## 直方图
假设$n$个数据落在$[a,b]$，然后将数据**等分**为$m$个小区间，组距$\Delta=\frac{b-a}m$，组限为每个小区间的端点。
数出每个区间的内的数据个数，即每个小区间内数据的频数$f_i$，算出频率$\frac {f_i}n$
## 箱线图
**定义**：设有容量为 $n$ 的样本观察值 $x _ { 1 }, x _ { 2 }, \cdots, x _ { n }$，样本 $p$ 分位数 $( 0 { < } p { < } 1 )$ 记为 $x _ { p }$ ，它具有以下的性质：（1)至少有 $n p$个观察值小于或等于 $x _ { p }, \, ( 2 )$ 至少有 $n ( 1 - p )$ 个观察值大于或等于 $x _ { p }$ 
# 抽样分布
**定义**：设$X_1,X_2,...,X_n$是来自总体$X$的一个样本，$g(X_1,X_2,...,X_n)$是$X_1,X_2,...,X_n$的函数，若$g$中不含未知参数，则称其为**统计量**

![[Pasted image 20260721151319.png|513]]
由辛钦大数定理，每个$A_k\stackrel{P}{\longrightarrow}\mu_k$，对于连续的$g$，有$g(A_1,A_2,...,A_k)\stackrel{P}{\longrightarrow}g(\mu_1,\mu_2,...,\mu_k)$

**定义**（经验分布函数）：设$x_1,x_2,...,x_n$是来自分布函数为$F(x)$的总体$X$的样本观察值.$X$的经验分布函数，记为
$$F_n(x)=\dfrac{\#(x_i\le x)}{n},\qquad-\infty<x<\infty$$
**定理**(Glivenko)：设$X_1,X_2,...,X_n$是来自以$F(x)$为分布函数的总体$X$的样本，$F_n(X)$是经验分布函数，则有
$$
P\left\{\lim_{n\to\infty}\sup_{-\infty<x<\infty}|F_n(x)-F(x)|=0\right\}=1
$$
意味着当$n$足够大时，经验分布函数可以很好地逼近分布函数
## $\chi^2$分布
设$X_1,X_2,...,X_n$是来自总体$\mathcal N(0,1)$的样本，称统计量
$$
\chi^2=X_1^2+X_2^2+...+X_n^2
$$
服从自由度为$n$的$\chi^2$分布，记为$\chi^2\sim\chi^2(n)$. 其中自由度$n$指式子右端包含的独立变量个数
$\chi^2$分布的概率密度为：
$$
f(x)=  
\begin{cases}  
\dfrac{1}{2^{n/2}\Gamma(n/2)}y^{n/2-1}e^{-y/2}, & y>0,\\[6pt]  
0, & \text{其他}.  
\end{cases}
$$
> [!NOTE] $\Gamma$ 分布
> 假设$X_1,X_2,...,X_n$为连续发生事件的等候时间，且这$\alpha$次（这里不要求$\alpha$为整数）等候时间相互独立，那么随机变量$Y=(X_1+X_2+...+X_n)\sim \Gamma(\alpha,\beta)$，$\beta$为事件发生一次的概率.
> 其概率密度函数为
> $$
> f(x)=\dfrac{1}{\beta^\alpha\Gamma(\alpha)}x^{\alpha-1}e^{-\frac x\beta}
> $$
