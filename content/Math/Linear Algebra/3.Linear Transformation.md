# 向量空间的线性映射
**记号**：从 $V$ 到 $W$ 的所有线性映射构成的集合记为 $\mathcal L(V,W)$. 这里$V,W$是向量空间

**线性映射**：
- 微分：定义$D\in\mathcal L(\mathcal P(\mathbb R),\mathcal P(\mathbb R))$：
  $$Dp=p'$$
- 积分：定义$T\in\mathcal L(\mathcal P(\mathbb R),\mathbb R)$：
  $$Tp=\int_0^1p(x)dx$$
- 向后移位：定义$T\in\mathcal L(\mathbf F^\infty,\mathbf F^\infty)$：
  $$T(x_1,x_2,x_3,...)=(x_2,x_3,...)$$

**定理**：设$v_1,...,v_n$是 $V$ 的基，$w_1,...,w_n$是 $W$ 的基，则存在唯一的线性映射$T:V\to W$ 使得：
$$
\forall j=1,...,n,\ Tv_j=w_j
$$

**性质**：设 $T$ 是 $V$ 到 $W$ 的线性映射．则 $T ( 0 ) = 0.$

**$\mathcal L(V,W)$上的加法和标量乘法**：设$S,T\in\mathcal L(V,W)$，$\lambda \in \mathbf F$. $和S+T$与$积\lambda T$是$V$到$W$的线性映射：
$$
(S+T)(v)=Sv+Tv,\quad(\lambda T)(v)=\lambda(Tv)
$$
所以，$\mathcal L(V,W)$对加法与标量乘法封闭，这是一个**向量空间**

**线性映射的乘积**：若 $T \in { \mathcal { L } } ( U, V ), S \in \mathcal { L } ( V, W )$ ，则定义乘积 $S T \in { \mathcal { L } } ( U, W )$ 如下：
$$\forall u \in U,\ ( S T ) ( u ) = S ( T u ).$$
注意两个的定义域值域，要确保映射有意义

# 零空间与值域
**零空间**：对于 $T \in { \mathcal { L } } ( V, W )$  $T$ 的零空间（记为 $\mathrm { n u l l } \, T )$  是指$V$中那些被 $T$ 映为 $0$ 的向量构成的子集：
$$
\operatorname { n u l l } T = \{ v \in V : T v = 0 \}.
$$

**定理**：设 $T \in { \mathcal { L } } ( V, W )$，则 $\operatorname { n u l l } T$ 是 $V$ 的子空间

**单射**：若 $Tu=Tv\Longrightarrow u=v$，则称映射为**单射**
不难看出，$\text{null } T=\{0\}$ 和 $T$ 为单射等价

**值域**：对于 $V$ 到 $W$ 的映射 $T$ , $T$ 的值域是 $W$ 中形如 $T v$ （其中 $v \in V$ ）的向量组成的子集：
$$
\operatorname { r a n g e } T = \{ T v : v \in V \}.
$$

**满射**：如果函数 $T \colon V \to W$ 的值域等于 $W$ ，则称 $T$ 为满射

**线性映射基本定理**：设 $V$ 是有限维的，$T \in \mathcal { L } ( V, W )$，则 $\mathrm { r a n g e } \, T$ 是有限维的并且
$$
\dim V = \dim n \mathrm { u l l } \, T + \dim \mathrm { r a n g e } \, T.
$$
**定理**：
- 如果 $V$ 和 $\mathit { W }$ 都是有限维向量空间，并且 $\operatorname { d i m } V < \operatorname { d i m } W$，那么 $V$ 到 $W$ 的线性映射一定不是满的
- 如果 $V$ 和 $W$ 都是有限维向量空间，并且 $\operatorname { d i m } V > \operatorname { d i m } W$，那么 $V$ 到 $W$ 的线性映射一定不是单的.

**齐次线性方程组问题**：
$$
\begin{cases}
\displaystyle \sum_{k=1}^{n} A_{1,k}x_k = 0,\\
\qquad \vdots\\
\displaystyle \sum_{k=1}^{n} A_{m,k}x_k = 0.
\end{cases}
$$
考虑如下线性映射$T:\mathbf F^n\to\mathbf F^m$
$$
T ( x _ { 1 }, \ldots, x _ { n } ) = \bigl ( \sum _ { k = 1 } ^ { n } A _ { 1, k } x _ { k }, \ldots, \sum _ { k = 1 } ^ { n } A _ { m, k } x _ { k } \bigr ).
$$
显然有一个解是所有变量都为 $0$，不过还有解吗？——看 $\text{null }T$ 的维度即可

对于非齐次线性方程也是同样的研究方式——我们使用上面单射、满射的定理就能得到当变量和方程的数量不等时，解的情况
