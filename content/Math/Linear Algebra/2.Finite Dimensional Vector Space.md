# 张成空间与线性无关
> [!NOTE] 记号 向量组
> 表示向量组时，通常不用括号括起来

**（线性）张成空间**：记
$$
\text{span}(v_1,...,v_m)=\{a_1v_1+...+a_mv_m|a_1,...,a_m\in \mathbf F,v_1,...,v_m\in V\}
$$
特殊地，$\text{span}()=\{0\}$

**定理**：张成空间是包含这组向量的最小子空间
证明：子空间的证明是显然的，下证这个子空间是最小的：
假设存在一个更小的子空间$V'\subsetneq \text{span}(v_1,...,v_m)$，那么$\exists v\in \text{span}(v_1,...,v_m)/ V'$，所以$v$可以表示为$v_1,...,v_m$的线性组合，又因为$v_1,...,v_m\in V'$而$v\notin V'$，则$V'$不是子空间，矛盾！

**张成**：$V=\text{span}(v_1,...,v_m)$，则称$v_1,...,v_m张成 V$

**多项式**：
- 对于函数$p:\mathbf F\to \mathbf F$，若存在$a_0,...,a_m\in \mathbf F$使得对于任意$z\in\mathbf F$，有：
  $$p(z)=a_0+a_1z+a_2z^2+...+a_mz^m$$
  则称$p$为**系数属于$\mathbf F$的多项式**
- $\mathcal P(\mathbf F)$ 是系数属于$\mathbf F$的全体多项式组成的集合，也是$\mathbf F$上的向量空间

**次数**：规定恒等于 $0$ 的多项式的次数为 $-\infty$

**定义**：$\mathcal P_m(\mathbf F)$表示系数在$\mathbf F$中且次数不超过$m$的所有多项式构成的集合

**引理**：在有限维向量空间中，线性无关向量组的长度小于等于向量空间的每一个张成组的长度（张成组是针对一个向量空间来说的）

**定理**：有限维向量空间的子空间是有限维的
# 基
**基**：若$V$中的一个**向量组**既线性无关又张成$V$，则称为$V$的基
**判定**：
$$
v_1,...,v_n是V的基\Longleftrightarrow \forall v\in V,v=a_1v_1+...+a_nv_n\quad a_i\in \mathbf F且唯一
$$

**定理**：设 $V$ 是有限维的， $U$ 是 $V$ 的子空间，则存在$V$的子空间 $W$ 使得 $V = U$ ⊕ $W$

**定理**：在向量空间中，每个张成组都可以化简成基（后面经常用于证明）
# 维度
**维数**：有限维向量空间的任意基长度称为向量空间的维数，有限维向量空间的维数记为$\dim V$

**定理**：若 $V$ 是有限维的，则 $V$ 中每个长度为 $\operatorname { d i m } V$ 的线性无关向量组都是 $V$ 的基；$V$ 中每个长度为 $\operatorname { d i m } V$ 的张成向量组都是 $V$ 的基.

**定理**：如果 $U _ { 1 }$ 和 $U _ { 2 }$ 是有限维向量空间的两个子空间，则
$$
\dim ( U _ { 1 } + U _ { 2 } ) = \dim U _ { 1 } + \dim U _ { 2 } - \dim ( U _ { 1 } \cap U _ { 2 } ).
$$
