### sum
#### 降维sum
在调用函数时指定`axis=0`。 由于输入矩阵沿0轴降维以生成输出向量，因此输入轴0的维数在输出形状中消失。
```
>>> A_sum_axis0 = A.sum(axis=0)
>>> A_sum_axis0
tensor([40., 45., 50., 55.])
```
沿着`axis=0`求和，shape由(5, 4)变为(4)
任何有求和的函数，如`mean()`都可以指定
#### 非降维sum
可以保持轴数不变，有利于广播
```
>>> sum_A = A.sum(axis=0, keepdims=True)
>>> sum_A
tensor([[40., 45., 50., 55.]])
```
这里相当于是shape由(5, 4)变为(1, 4)了

# 自动微分
深度学习框架通过自动计算导数，即自动微分（automatic differentiation）来加快求导。 实际中，根据设计好的模型，系统会构建一个计算图（computational graph）， 来跟踪计算是哪些数据通过哪些操作组合起来产生输出。 自动微分使系统能够随后反向传播梯度。
## Example
$y = 2 \mathbf { x } ^ { \top } \mathbf { x }$
```
x = torch.arange(4.0)
x.requires_grad_(True)
# 等价于x = torch.arange(4.0,requires_grad=True)
y = 2 * torch.dot(x, x)
```
调用反向传播函数来**自动计算`y`关于`x`每个分量的梯度**
```
>>> y.backward()
>>> x.grad
tensor([ 0.,  4.,  8., 12.])
```
在默认情况下，PyTorch会累积梯度（实际上，大部分情况下都是要累积梯度）
```
>>> y = x.sum()
>>> y.backward()
>>> x.grad
tensor([ 1.,  5.,  9., 13.])
```
我们需要清除之前的值
```
>>> x.grad.zero_()
tensor([0., 0., 0., 0.])
>>> y = x.sum()
>>> y.backward()
>>> x.grad
tensor([1., 1., 1., 1.])
```
## 非标量反向传播
如果输出不是标量，不能直接裸调用 `y.backward()`
```
>>> y = x * x
>>> y.backward()
Traceback (most recent call last):
RuntimeError: grad can be implicitly created only for scalar outputs
```
正确应该这么做
```
>>> x.grad.zero_()
tensor([0., 0., 0., 0.])
>>> y = x * x
>>> # 等价于y.backward(torch.ones(len(x)))
>>> y.sum().backward()
>>> x.grad
tensor([0., 2., 4., 6.])
```
这里backward传入的参数是
```
v = torch.tensor([...])  
y.backward(v)
```
 也就是求$\frac { \partial ( v ^ { \top } y ) } { \partial x }$
## 分离计算
有时，我们希望将某些计算移动到记录的计算图之外.
假设在计算图中，`y`是作为`x`的函数计算的，而`z`则是作为`y`和`x`的函数计算的。但是我们希望在计算`z`关于`x`的梯度时，将`y`视作常数
```
>>> y = x * x
>>> u = y.detach()
>>> z = u * x
>>> z.sum().backward()
>>> x.grad
tensor([0., 1., 4., 9.])
```
如果不用`detach()`，计算的就是`x * x * x`的梯度
```
>>> y = x * x
>>> u = y
>>> z = u * x
>>> z.sum().backward()
>>> x.grad
tensor([ 0.,  3., 12., 27.])
```
## Python控制流的梯度计算
即使函数里有 Python 控制流，比如 `while`、`if`、循环次数随输入变化，PyTorch 仍然可以对实际执行过的计算路径做反向传播。
```
>>> def f(a):
...     b = a * 2
...     while b.norm() < 1000:
...         b = b * 2
...     if b.sum() > 0:
...         c = b
...     else:
...         c = 100 * b
...     return c
...
>>> a = torch.randn(size=(), requires_grad=True)
>>> d = f(a)
>>> d.backward()
>>> a.grad == d / a
tensor(True)
```
这里b乘以的2的个数和a有关，c最后返回的值也和a有关，总体来说，这个函数是线性的。Pytorch也可以很好地处理Python控制流

# 概率
## 边际化(全概率)
为了能进行事件概率求和，我们需要求和法则（sum rule）， 即的概率相当于计算的所有可能选择，并将所有选择的联合概率聚合在一起：
$$P ( B ) = \sum _ { A } P ( A, B )$$这也称为边际化（marginalization）。 边际化结果的概率或分布称为边际概率（marginal probability） 或边际分布（marginal distribution）。
## 似然
概率，用于在已知一些参数的情况下，预测接下来在观测上所得到的结果
似然性，则是用于在已知某些观测所得到的结果时，对有关事物之性质的参数进行估值，也就是说已观察到某事件后，对相关参数进行猜测
对于高斯密度函数来说，当我们观察到了$x_1,\dots,x_n$（这些是固定的值），似然函数为（$\mu,\sigma$是变量）
$$L ( \mu, \sigma ) = \prod _ { i = 1 } ^ { n } \frac { 1 } { \sqrt { 2 \pi } \sigma } \operatorname { e x p } \left( - \frac { ( x _ { i } - \mu ) ^ { 2 } } { 2 \sigma ^ { 2 } } \right)$$
