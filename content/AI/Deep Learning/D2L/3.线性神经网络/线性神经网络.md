# 线性回归
**为什么是均方误差损失函数？**
我们先有**假设**——噪声符合均值为0的正态分布
$$y = \mathbf { w } ^ { \top } \mathbf { x } + b + \epsilon,$$
给定$\mathbf { x }$观察到特定$y$的似然为：
$$P ( y \mid \mathbf { x } ) = \frac { 1 } { \sqrt { 2 \pi \sigma ^ { 2 } } } \operatorname { e x p } \left( - \frac { 1 } { 2 \sigma ^ { 2 } } ( y - \mathbf { w } ^ { \top } \mathbf { x } - b ) ^ { 2 } \right).$$
这里的意思是：在给定 $\mathbf{x}$ 的情况下，如果模型参数是 $\mathbf{w},b$，那么观测到这个 $y$ 的可能性有多大
对于整个样本$X$我们有：$$P ( { \bf y } \mid { \bf X } ) = \prod _ { i = 1 } ^ { n } p ( y ^ { ( i ) } \mid { \bf x } ^ { ( i ) } )$$
取对数得到$$- \operatorname { l o g } P ( \mathbf { y } \mid \mathbf { X } ) = \sum _ { i = 1 } ^ { n } \frac { 1 } { 2 } \operatorname { l o g } ( 2 \pi \sigma ^ { 2 } ) + \frac { 1 } { 2 \sigma ^ { 2 } } \Big ( y ^ { ( i ) } - \mathbf { w } ^ { \top } \mathbf { x } ^ { ( i ) } - b \Big ) ^ { 2 }$$我们发现，最小化均方误差$\Big ( y ^ { ( i ) } - \mathbf { w } ^ { \top } \mathbf { x } ^ { ( i ) } - b \Big ) ^ { 2 }$等价于对线性模型的极大似然估计。也就是对于给定的输入，满足均方误差最小的模型参数，可以使得观测到的这些$y$（正确标签）的可能性（或者密度）最大
# 实现线性回归
```python
def sgd(params, lr, batch_size):  #@save
    """小批量随机梯度下降"""
    with torch.no_grad(): #梯度下降更新参数的不需要计算图
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()
```

> [!NOTE] 关于backward()
> `loss.backward()` 会沿着计算图反向传播，并把梯度累积到所有参与计算、且 `requires_grad=True` 的叶子张量的 `.grad` 里。

## 定义模型
`Sequential`为一个Class，用于实现每一个层
```python
# nn是神经网络的缩写
from torch import nn

net = nn.Sequential(nn.Linear(2, 1))
```
## 初始化模型参数
```python
net[0].weight.data.normal_(0, 0.01) #传入的参数分别是均值和标准差
net[0].bias.data.fill_(0)
```
## 定义损失函数
```python
loss = nn.MSELoss() # 均方误差
```
默认返回所有样本损失的平均值
## 定义优化算法
需要指定要优化的参数，可以用`net.parameters()`获得
```python
trainer = torch.optim.SGD(net.parameters(), lr=0.03)
```
SGD只需要指定lr

## 训练
三个步骤：
- 通过调用`net(X)`生成预测并计算损失`l`（前向传播）
- 通过进行反向传播来计算梯度
- 通过调用优化器来更新模型参数
