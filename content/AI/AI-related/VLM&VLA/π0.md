# The $\pi_0$ Model
## Architecture
![[Pasted image 20260730112431.png]]
主要由语言模型 Transformer 骨干组成，由并行的两个 Transformer 块构成，两个块之间通过Self-Attention 交流
$$
[\text{VLM token},\ q_t,\ a_t^\tau,...,a_{t+49}^\tau]
$$
被Transformer读取，这两个块分别有自己的参数，但是最后的$Q,K,V$由两个块的矩阵拼接，最终由Self-Attention Layer交流

最终通过[[Flow Matching]]生成动作
## 流程
模型的目的是建模$p(A_t\mid o_t)$，其中$A_t=[a_t^\tau,...,a_{t+49}^\tau]$，$o _ { t } = ( I _ { t } ^ { 1 }, \ldots, I _ { t } ^ { n }, \ell _ { t }, q _ { t } )$
$A_t$是包含$H$个动作的**动作块**，$I_t^i$是**多视角图像**，$\ell_t$是**语言任务**，$q_t$是**当前机器人状态**

模型输入$o_t$，其中多视角图像和语言任务由VLM处理，机器人状态（如舵机状态）和带噪动作块由action expert处理（初始$A_t^0\sim\mathcal N(0,I)$）
注意，这里$\pi_0$之所以叫**连续动作的VLA**是因为每一个动作$a_t$是在高维**实数空间**的向量

我们运行N次模型，**每次模型输出Vector Field在当前位置施加的向量**
$$
v_k=v_\theta(A_t^{\tau_k},o_t,\tau_k)\qquad\tau_k=\frac{k-1}{N}是\text{Flow Matching}的时间
$$
然后使用Euler Method进行ODE Sampling
$$
\boxed { A ^ { 0 } \stackrel { \pi _ { 0 } } { \longrightarrow } v _ { 0 } \stackrel {   \text{演化}  } { \longrightarrow } A ^ { 0. 1 } \stackrel { \pi _ { 0 } } { \longrightarrow } v _ { 1 } \stackrel {\text{演化} } { \longrightarrow } \cdots \to A ^ { 1 } }
$$
