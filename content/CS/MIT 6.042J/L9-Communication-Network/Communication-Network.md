# Complete Binary Tree
![[Pasted image 20260607103710.png|301]]
**Switch**（圆形）：引导数据包通过网络，$n\times n$的交换器说明有n个入度和n个出度
**Terminal**（方形）：数据的源或者目的地
**Latency**：从数据包从输入传输到输出所需的时间
**Diameter**：相距最远的输入和输出之间的最短路径的长度。比如上图的网络直径就是从In0到Out2或Out4的距离（等于6）
**Permutation**：双射$\pi:\{0,1,\ldots,N-1\}\mapsto\{0,1,\ldots,N-1\}$
>Permutation Routing Problem：
>   对于每一个$i$，希望将输入$i$的数据包引导到$\pi(i)$：路由的路径为$P_{i,\pi(i)}$

**Congestion**：路径$P_{0,\pi(0)},\ldots,P_{N-1,\pi(N-1)}$的拥塞定义为**通过单个交换机的最大路径数**，比如上图
**Maximum Congestion**：**对于每一种排列**，我们选择一组路径**使得拥塞尽量小**（防止在两个Switch之间打转等情况），然后**在所有排列里取最坏情况**所得到的拥塞。即所有边中，被最多条路径共同经过的那条边的使用次数。比如上图的最大拥塞为4（都经过root）
# 2D Array
![[Pasted image 20260607113132.png|420]]
2D Array的Maximum Congestion为2
>Proof.
>对于任何一种排列，我们提出一种路由方法，先从$i$行一直往右走到$\pi(i)$列，再一直往下到Out，显然每个节点最多被使用2次。
>由于最大拥塞需要最优的路由方法，这个最优的路由方法对应的拥塞一定$\le 2$，所以最大拥塞$\le 2$，也就是$\max_\pi C ^ { * } ( \pi ) =\max_\pi \operatorname* { m i n } _ { R \in \mathcal { R } _ { \pi } }\mathrm { c o n g e s t i o n } ( R ) \leq \mathrm { c o n g e s t i o n } ( R _ { \pi }) \leq 2$
>所以，我们要证明有一个排列，可以使得拥塞取到2，这是显然的
# Butterfly
![[未命名绘图.drawio (3).png|566]]
每一个**交换机**由其行和列唯一标识$(b_1,...,b_{\log N},l),b_i\in\{0,1\}$，其将信息斜向或者水平发送：$(b_1,...,\bar{b_{l+1}},...,b_{\log N},l+1)$或者$(b_1,...,b_{l+1},...,b_{\log N},l+1)$
注意，对于$110$来说，$b_1=1,b_2=1,b_3=0$
我们可以把路由也数学形式化：路由是依次从$b_1到b_{l_N}$把位取反或不变，每次如此操作后都把最后一个元素$l$加1
# Benes
两个Butterfly背靠背
![[未命名12321.drawio.png]]
定理：$n\times n$的Benes网络的最大阻塞是1，其中$n=2^a$
>Proof.
>我们对a进行归纳，不变量P(a)：“定理对a成立”
>$P(1)$：显然成立
>$P(a)\to P(a+1)$：我们只需要描述一个路由方法，使得其对于所有的排列，阻塞都为1即可
>由于递归的性质，只要数据进入了中间的小网络，那么能直接用归纳假设。所以我们要约束，子网络里的任意交换器，必须**只能接受一个来源的数据包，且只能发送给一个对象**
>注意子网络由归纳假设得到的性质是——**左边依次为$1,2,..,N$，右边可以在阻塞为1的情况下为这$N$个数的全排列**。
>我们构建一个约束图：如果两个数据包必须通过不同的子网络（蓝色框、红色框...），我们给这两个之间连一条边
>接收：
>比如在上图中，0和4不能发送到同一个子网络（对应蓝色的4x4网络），否则$(0,0,0,1)$的入度为2,
>发送
>比如在上图中，发送到1和5的包不能进入一个子网络，否则发出的时候，都要使用$(0,0,1,5)$的交换器才能出去
>接下来，我们只需要证明这个约束图可以使用两种颜色着色即可（对应两个子网络），再加强一下命题，我们要证明这个约束图是每个顶点的度都为2偶环：
>1. 证明每个顶点的度为（小于等于）2：
>如果存在一个顶点的度大于2，说明该数据包和至少两个数据包**不能在同一个网络中**，那么那些包**一定在同一个网络中**，显然，我们总能找到一种排序，使得那些包冲突，矛盾！
>2. 证明不是奇环，使用反证法：
>如果存在一个奇环，假设存在一个顶点的两条边都为实线，由于每个顶点一定和一个顶点输入冲突和一个顶点输出冲突，那么这个顶点必须连接一条虚线，又由于每个顶点的度小于等于2，矛盾！

\end{aligned}
